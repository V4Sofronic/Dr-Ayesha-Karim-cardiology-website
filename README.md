# Dr. Ayesha Karim — Cardiology Website

A responsive website for Dr. Ayesha Karim's cardiology practice, designed to present medical services, doctor information, and patient-focused healthcare content through a clean and accessible interface.

## Overview

This website provides visitors with information about the cardiology practice, its services, and relevant patient information.

## Live Link 
https://dr-ayesha-karim-cardiology-website.pages.dev/

## Technologies

- CSS3
- JavaScript
- Google Fonts
